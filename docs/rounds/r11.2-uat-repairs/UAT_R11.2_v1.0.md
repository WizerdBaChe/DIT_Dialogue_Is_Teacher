## 啟動方式（**這次一定要用建置版**）

R11 的驗收卡寫了 `npm run dev`，而 `exportHtml()` 開頭就是 `if (import.meta.env.DEV) return;`——快照匯出在 dev 下**刻意停用**，因為它要 `fetch("./snapshot.html")`，而那份模板是 `vite build` 的產物。C1／C2 因此被誤判為未通過。這次全程用建置版，一種模式驗到底：

```powershell
npm run build
npm run preview
```

開啟 `http://localhost:4173`。
