## 怎麼用這份清單

每一項都是「**動作 → 預期觀察**」，寫成不需要讀過本輪對話也能照做。逐項填 **通過／未通過／無法判定**，未通過請附上你實際看到什麼（照抄畫面文字即可，不必判斷成因）。

啟動：

```powershell
npm run dev
```

## B　核心驗收（happy path）

| # | 動作 | 預期觀察 |
|---|---|---|
| B1 | 進入「閱讀」，用 **Tab 鍵**移動到側欄符號圖例的第一個符號 | 該符號獲得焦點時**泡泡自動顯示**（不需要滑鼠）。繼續 Tab 應逐一切換到下一個符號。**此項我無法自動驗證**（分頁非前景時 `:focus` 本來就不匹配），必須由你按鍵確認 |
| B2 | 同上，比對圖例整體排版 | 仍是四欄符號網格，沒有變成一長條或擠成兩欄；沒有出現「符號說明」這種需要點開的收合標題 |
| B3 | 點「從對話集選擇」，挑一個含 **Codex** session 的資料夾 | 清單裡**看得到 Codex 的 session**（以前完全不會出現）。每一列可看出來源。Codex 的列不應出現「子代理」關聯 |
| B4 | 同一份清單裡找一個標成「無法判定」的項目 | 它**仍然列在清單上**而不是消失。滑過分類標籤應說明為何無法判定 |
| B5 | 開啟一個 **Codex** session 進入閱讀 | **同一段思考不會連續出現兩張幾乎一樣的卡片**（這是本輪修掉的重複思考鏈） |
| B6 | 在同一個 Codex session 裡尋找卡片標題 | 標題**不應出現** `[external_agent_tool_result]` 這類方括號包裝字樣，而且原本被它吃掉的內容應該讀得到 |
| B7 | 看該 session 的診斷／警告區 | 未能配對的事件**不再以警告樣式**呈現，也**不再宣稱「多半是壓縮」**。文案只說來源沒有記錄足以配對的資訊 |
| B8 | 設定 → 匯出面板 | 「同時遮蔽高熵字串（實驗性）」checkbox 存在且**預設未勾**，下方提示說明它必然會誤抓無害字串 |
| B9 | 載入一個含長亂數字串（token／雜湊／UUID）的 session，只勾「遮蔽敏感資訊」，匯出 Markdown | 該字串**仍看得到**，且標頭出現一行「另偵測到 N 筆疑似高熵字串（未遮）」 |
| B10 | 同一份，再加勾高熵 checkbox，重新匯出 | 該字串被換成 `<HIGH_ENTROPY_1>` 之類的佔位符，且「另偵測到…」那行**消失**（數字為 0） |
| B11 | 設定講解供應商為需要外傳的雲端供應商，對第一則做「講解」，在隱私複核視窗按同意 | 講解正常完成 |
| B12 | 緊接著對**第二則**做「講解」 | **不應再次跳出隱私複核**（同一個 session、同一組設定只需同意一次）。這個行為在本輪之前從未生效過 |
| B13 | 匯出「純對話紀錄」 | 內容是人讀的對話；**預設不含**工具呼叫的逐行摘要，但統計標頭仍誠實寫出「工具呼叫 N（未納入）」 |
| B14 | 看設定裡匯出區塊的名稱 | 兩區分別是「匯出閱讀頁面快照」與「匯出純對話紀錄」，讀得出是兩件不同的事 |
| B15 | 找一個含子代理群組的 session，看群組卡片的分類標籤 | 顯示「子代理」而不是一律顯示「群組」；反覆修改與重試也各自顯示自己的名稱 |

## C　壓力與邊界（**至少要做完，這裡比 happy path 更容易抓到問題**）

| # | 動作 | 預期觀察 |
|---|---|---|
| C1 | 匯出「閱讀頁面快照」，**斷網**後用瀏覽器直接開那個 HTML 檔 | 正常顯示。開發者工具的 Network 面板**沒有任何外部請求**（尤其不該有 `dit.config.json`）。畫面不應出現「載入」卡住或空白 |
| C2 | 快照檔裡不應有設定入口 | 快照模式下不出現「載入檔案／從對話集選擇」等會改動內容的操作 |
| C3 | 在 B8 的 checkbox 上**快速連續切換 5 次以上**再匯出 | 匯出結果符合**按下匯出當下**的勾選狀態，不是中間某個狀態；沒有 console 錯誤 |
| C4 | 一段訊息裡同時有真密鑰（`sk-…`）與其他長亂數字串，勾選高熵後匯出 | 密鑰仍變成 `<SECRET_1>`（不被高熵規則吃掉），不崩潰、無 console 錯誤 |
| C5 | 選一個**很大的**資料夾（數百個 session）做索引 | 不卡死；清單出得來；期間切換到別的分頁再切回來不應變成空白或永久「索引中」 |
| C6 | 索引過程中途**關閉對話框**再重開 | 不會卡在「索引中」，也不會殘留上一次的結果 |
| C7 | 挑一個**第一行超長**（夾帶截圖 base64）的 session 檔 | 它仍被正確辨識來源並列出，不會因為第一個視窗讀不完整就被當成「不是我們的檔案」而消失 |
| C8 | 在隱私複核視窗按**取消** | 該則講解中止，不會留下已同意的假象；再次講解時應**重新**跳出複核 |
| C9 | 隱私複核開啟時，按 Esc 或點背景 | 焦點不被背景的「設定」按鈕搶走；關閉行為一致 |
| C10 | 開啟 Session 地圖，用鍵盤 Tab 走過圖例 | 每個符號可獲得焦點且泡泡顯示；地圖本身的縮放與跳轉不受影響 |
| C11 | 切到窄視窗（或縮小瀏覽器寬度）再看側欄圖例 | 圖例不溢出、不遮住內容；抽屜模式下仍可正常開關 |
| C12 | 連續匯出同一份 session 的 Markdown 與 HTML（都開啟遮蔽） | 同一個原始值在兩份檔案裡對到**相同的佔位符編號** |

## D　已知不在本輪、看到也不算缺陷

以下是**已裁決留給 R12** 的項目，驗收時看到請**不要**記為未通過：

- Markdown／LaTeX 不會被渲染，反引號與語法會原樣顯示（D-005，另立 r11.1）。
- Codex session 的骨架常常只有頭尾兩站、中段沒有「決策」節點（D-011，R12 處理）。
- 未配對事件的卡片**尚未**在視覺上降權（D-010，WC-4.3 依賴 P1，R12）。
- 單檔快照匯出**不做**遮蔽、也沒有高熵揭露句（資安複核 §3，待你裁示是延伸揭露還是明文記錄為排除）。
- 高熵 checkbox 在主開關「遮蔽敏感資訊」關閉時是無效的，且沒有提示（資安複核 §2，待你裁示方向）。
- `git log --oneline` 那種 7–12 字元的縮寫雜湊不會被高熵規則抓到（完整 40／64 字元的會，D-009）。
